# automed-plataforma-diagnostico
Código fuente y conjunto de datos de una plataforma mecatrónica para diagnóstico automotriz de suspensión, frenado y alineación. Incluye firmware de adquisición (C++/ESP32) para sensores inerciales y celdas de carga, y una aplicación de escritorio (Python) para procesamiento y aprendizaje automático.
